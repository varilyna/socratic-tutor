# Сократический тьютор

Приложение для обучения через диалог на основе прочитанного текста. Пользователь
вставляет материал или загружает TXT, Markdown либо DOCX. GigaChat выделяет
учебные цели и готовит задания. Тьютор задаёт вопросы, помогает разобраться
в ошибках и проверяет понимание на новых примерах.

Для демонстрации используется текст об OKR из тестового задания. Можно
загрузить другой учебный материал.

## Запуск

Нужен Python 3.11 или новее. Если окружение `.venv` уже подготовлено,
повторно создавать его и устанавливать зависимости не нужно.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Создайте в корне проекта файл `.env` и заполните настройки:

```dotenv
GIGACHAT_AUTH_KEY=ваш_ключ_авторизации
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2-Pro
GIGACHAT_BASE_URL=https://gigachat.devices.sberbank.ru/api/v1
GIGACHAT_AUTH_URL=https://ngw.devices.sberbank.ru:9443/api/v2/oauth
GIGACHAT_CA_BUNDLE=certs/russian_trusted_root.crt
```

Если `.env` уже настроен, используйте существующий файл. `GIGACHAT_AUTH_KEY`
должен содержать Authorization Key вашего проекта GigaChat. Временный токен
доступа клиент получает и обновляет автоматически. Модель и область доступа
должны соответствовать вашему проекту.

Запустите приложение из корня проекта:

```bash
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1
```

Откройте в браузере `http://127.0.0.1:8501`. После изменения `.env`
перезапустите приложение. Переменные окружения имеют приоритет над файлом.
Проверка TLS включена, указанный сертификат используется только приложением.

## Как пользоваться

1. Нажмите «Взять пример OKR из задания», загрузите файл или вставьте свой текст.
2. Нажмите «Подготовить обучение» и ознакомьтесь с предложенными целями.
3. Начните диалог и отвечайте на вопросы, объясняя ход мысли.
4. При необходимости запросите подсказку.
5. В конце просмотрите итог и при желании скачайте диалог и результаты.

Кнопка «Завершить с итогом» позволяет закончить сессию раньше.
«Начать заново» сбрасывает текущий план и диалог.

Учебный текст должен содержать от 150 до 14 000 символов. Размер загружаемого
файла проверяется кодом: до 2 МБ. Текстовые файлы должны быть в UTF-8.

## Как устроен диалог

Подготовка проходит поэтапно: модель выделяет 2–4 учебные цели, затем создаёт
три задания для каждой цели. Код проверяет структуру плана, различие вопросов
и наличие цитат из исходного материала.

Во время диалога отдельный запрос к модели оценивает ответ ученика. Контроллер
на Python выбирает следующий шаг: уточнение, подсказку, объяснение, новую
задачу или завершение. Затем модель формулирует реплику тьютора, которая
проходит дополнительную проверку.

Один правильный ответ ещё не подтверждает освоение навыка: нужно решить другой
пример самостоятельно. Ответ после подсказки учитывается как практика с
помощью. Если ученик застрял, помощь постепенно усиливается до объяснения.
Сессия ограничена 20 ответами, её завершение не означает, что все навыки освоены.

При технической ошибке учебный переход не сохраняется, а ответ остаётся
доступным для повторной обработки.

## Структура проекта

| Файл или папка | Назначение |
|---|---|
| `app.py` | Интерфейс Streamlit, загрузка материала и управление сессией |
| `tutor/engine.py` | Подготовка плана, оценка ответов и переходы между заданиями |
| `tutor/prompts.py` | Инструкции для модели |
| `tutor/schemas.py` | JSON-схемы ответов модели |
| `tutor/provider.py` | Подключение к GigaChat, авторизация и обработка ошибок |
| `tutor/material.py` | Чтение файлов и проверка учебного текста |
| `data/okr.txt` | Демонстрационный материал из задания |
| `certs/` | Сертификат для подключения к API |
| `research/` | Исследование и обоснование решений |
| `requirements.txt` | Зависимости приложения |

## Исследование и выводы

В `research/Исследование.md` собраны результаты поиска научных работ, сылки на источники, основные выводы и их применение в проекте. 

## Ограничения и данные

Модель может ошибаться при составлении заданий и оценке ответов. Проверка
реплики той же моделью не является независимой проверкой. Учебный план можно
посмотреть до начала диалога. Его содержательную корректность нужно оценивать
вручную. Проверки с синтетическими учениками не доказывают эффективность
обучения людей.

Учебный текст и ответы отправляются в GigaChat API. Приложение автоматически
не записывает диалоги на диск: экспорт выполняется по кнопке пользователя.
Ключ не включается в экспорт. При передаче проекта исключите локальный `.env`.
Получателю нужен собственный ключ.
